## 四、简介（可直接全选粘贴，1727 字，未超 B 站 2000 字上限）

```
电脑上跑着 DSH（DeepSeek Harness），它自己读文件、写代码、跑命令，一个任务忙十几分钟。
你总不能一直盯着屏幕，所以我把它的界面搬到了一块手表上，抬腕就能看。
视频 70 秒，从痛点到装好，全流程都在里面。

【它能干什么】
· 按项目分组浏览所有会话，运行中的项目单独标出来
· 展开「思考」，看 AI 在说出那句话之前想了什么
· 展开工具调用，每一步读了哪个文件、跑了哪条命令、返回了什么
· 在手表上打字发消息、停止生成、往前翻历史
· AI 在等你回答时表盘会亮起来，单选、多选、打字都支持
· 换模型、看 token 用量与上下文占用
· 记住多台电脑，点一下就切过去

【用之前你需要】
1. 电脑上已经装好、并且正在运行 DSH 桌面版（本工具只负责搬画面，不包含 AI 本身）
2. 电脑是 Windows 10 1903 以上 或 Windows 11，双击即用，不用装 .NET 或 Node.js
3. 手表是 Android 8.0 以上、圆屏界面。测试机是 OPPO Watch 466×466，其它安卓或 Wear OS
   手表理论可用，但界面是按圆屏做的

【下载地址】
GitHub 仓库　https://github.com/DING-HAO-RAN/dsh-watch
最新版发布页　https://github.com/DING-HAO-RAN/dsh-watch/releases/latest

电脑端 DSH-Relay.exe（一个文件搞定）
https://github.com/DING-HAO-RAN/dsh-watch/releases/latest/download/DSH-Relay.exe
手表端 DSH-Watch.apk
https://github.com/DING-HAO-RAN/dsh-watch/releases/latest/download/DSH-Watch.apk

也可以从源码跑命令行版中继，需要 Node.js 22+，用法见仓库 README。

【三步装好】
第 1 步　下载 DSH-Relay.exe，双击运行。窗口里有 6 位配对码和几条地址，不用改任何设置。
第 2 步　手表装 APK：手表开启「开发者选项」和「USB 调试」（一般在「关于手表」里连点版本号），
　　　　 数据线连电脑并在手表上允许调试，然后执行：adb install -r DSH-Watch.apk
　　　　 没有 adb 的话，把 apk 传到手表上用文件管理器装也一样。
第 3 步　手表打开「DSH 手表」，左滑进设置，点「一键配对」。手表会自己找到同一 WiFi 下的电脑，
　　　　 电脑上弹窗点「是」就连上了。自动找不到就手动填窗口里那条「局域网」地址和配对码。

配对一次就记住，中继重启、程序升级都不会丢。

【常见问题】
Q 提示「没有找到 DSH」？先启动 DSH 桌面版再开中继，中继要读它的登录凭据。
Q 手表一直转圈？头和尾都在同一个 WiFi，地址填「局域网」那条 192.168.x.x，别填 127.0.0.1
  （那指向手表自己）；再检查电脑防火墙有没有拦 19390 端口。
Q 要公网服务器吗？局域网不用。出门用需要额外放一个 cloudflared.exe 到程序目录，会生成一条
  临时的 trycloudflare.com 地址，每次启动都变，该文件约 50MB 不随包提供。
Q 改 DSH 配置吗？装插件吗？都不会，中继只读凭据用于本机通信。
Q 关掉中继窗口就断？对，中继就跑在那个窗口里。
Q 一次能看多少？最多 40 条消息、60 个会话，更早的点「看更早的内容」分批加载。
Q 支持 iPhone 或 Apple Watch？不支持，手表端是原生 Android 应用。

【说明】
代码在 GitHub 上公开可看，自己用没问题；转载、二次分发请先联系作者。
局域网走明文 HTTP、靠 6 位配对码保护，只建议在信任的网络里开，用完关掉。
视频配音用的是曼波 TTS，画面由代码逐帧生成。
```

## 七、一个需要你决定的事

视频最后一句旁白是「开源免费，GitHub 搜 dsh watch」，但 README 末尾写的是
「本仓库未附带开源许可证。如需使用、修改或分发，请先联系作者」。

两条路，二选一：

1. **改成「免费自用，源码公开」**——重配最后一段旁白 + 重渲最后一镜（约 5 分钟）。
2. **给仓库加个 LICENSE**——之后「开源」就名正言顺，视频不用改。
   如果是这条路，得先想清楚用哪个协议；MIT 最宽松，也最符合「别人能拿去用」的初衷。

现在的投稿文案两种都不冲突（通篇没写「开源」），视频改不改都能发。
